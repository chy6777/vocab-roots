# vocab-roots

词根词缀解析工具：将 Excel(.xlsx) 或 CSV 格式的英语单词表转换为带「词根词缀解析」列的新版本，
逐词标注其 **前缀 / 词根 / 后缀** 及中文含义，辅助背单词。

例如单词 `rejection` 会被解析为：

```
前缀 re-(再/回/反复、向后) + 词根 ject(投/掷) + 后缀 -ion(名词后缀:…动作/状态) → 组合记忆
```

## 功能特性

- 内置大量前缀、后缀、词根字典（拉丁/希腊词根为主，含常用基础词汇补充）
- 自动启发式拆分：尝试多种前缀/后缀组合，按词根匹配质量评分选取最优分解
- 基础词/短词隔离：无法拆分的词（如 `the`、`apple`）解析列留空，避免误拆
- 输出 UTF-8 (BOM) 编码 CSV，Excel 直接打开不乱码
- 生成完成后打印统计：单词总数、解析成功数、覆盖率

## 环境要求

- Python 3.6+
- 仅转换 Excel 时需要：`pandas`、`openpyxl`

```bash
pip install pandas openpyxl
```

## 使用方法

### 1. 输入为 Excel(.xlsx)：先转 CSV

```bash
python excel_to_csv.py 输入.xlsx [输出.csv] [工作表名或序号]
```

- 输出文件缺省为同名 `.csv`（如 `词汇表.xlsx` → `词汇表.csv`）
- 工作表缺省为第一个；多工作表时请先确认要处理哪个表

示例：

```bash
python excel_to_csv.py 考研词汇_整理版.xlsx
python excel_to_csv.py data.xlsx result.csv Sheet2
```

### 2. 运行核心脚本

```bash
python add_roots.py 输入.csv [输出.csv] [单词列序号] [新列名]
```

参数说明（均可省略）：

| 参数 | 缺省值 | 说明 |
| --- | --- | --- |
| 输出.csv | `输入名_词根词缀版.csv` | 输出文件路径 |
| 单词列序号 | `0` | 单词所在列的序号（从 0 开始） |
| 新列名 | `词根词缀解析` | 新增列的名称 |

新列总是插入在单词列的**后面**。

示例：

```bash
python add_roots.py 单词表.csv
python add_roots.py 单词表.csv 词根词缀版.csv 2 词根词缀
```

### 3. 验证

脚本输出：

```
处理完成! 共 5500 个单词, 其中 4213 个生成了词根词缀解析, 覆盖率 76.6%
输出文件: 单词表_词根词缀版.csv
```

## 解析格式

```
前缀 re-(再/回) + 词根 ject(投/掷) + 后缀 -ion(名词后缀) → 组合记忆
```

各成分含义：

- `前缀 re-(再/回)`：前缀 + 中文含义
- `词根 ject(投/掷)`：词根 + 中文含义
- `后缀 -ion(名词后缀)`：后缀 + 词性说明
- 结尾的 `→ 组合记忆` 等提示是按成分组合给出的记忆辅助

## 常见问题

- **输入是 Excel，直接跑 add_roots.py 报错？** 核心脚本只接受 CSV，请先执行 `excel_to_csv.py` 转换。
- **某些单词解析列为空？** 属正常现象：短词、基础词（无法拆分词根词缀的词）会留空，如 `the`、`apple`、`make`。
- **输出文件被占用（PermissionError）？** 脚本会自动改输出到 `_new.csv` 结尾的文件。
- **单词表没有表头？** 脚本将第一行作为表头处理，请确保首行是表头。
- **适用范围？** 脚本假设单词在独立单元格中，不适用于整句/段落文本。
